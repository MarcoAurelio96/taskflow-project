# 📝 Next Task - Gestión de Tareas Inteligente

¡Bienvenido a Nex Task! Una aplicación web moderna diseñada para gestionar tus tareas diarias de forma eficiente, rápida y sin complicaciones.

## 🚀 Despliegue en Vivo
La aplicación se encuentra desplegada y operativa en la nube gracias a **Vercel**. Puedes acceder a ella a través del siguiente enlace:
👉 **https://taskflow-project-silk.vercel.app/**

---

## ✨ Características Principales
* **Gestión en Tiempo Real:** Crea, edita y elimina tareas con respuesta inmediata.
* **Priorización:** Organiza tus deberes según su importancia (Normal/Importante).
* **Estados de Red:** La interfaz te avisa cuando los datos se están cargando o si ha ocurrido algún error de conexión.
* **Fuente de Verdad Única:** Todos tus datos se gestionan de forma centralizada en un servidor remoto, eliminando la dependencia del almacenamiento local del navegador.

## 🛠️ Tecnologías Utilizadas
* **Frontend:** HTML5, CSS3 (Responsivo) y JavaScript (ES6+).
* **Backend:** Node.js y Express (Arquitectura REST).
* **Infraestructura:** Desplegado con Vercel Edge Functions.

## 💻 Ejecución Rápida en Local
Si deseas probar el proyecto en tu propia máquina:
1. Clona este repositorio.
2. Abre el archivo `index.html` en tu navegador.
3. Asegúrate de tener el servidor encendido (ver instrucciones técnicas en `/server`).
